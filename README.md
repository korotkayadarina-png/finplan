# Финансовый планер — сайт

Личный дашборд: бюджет, подушка, цели, прогноз капитала, портфель.
Сайт: https://korotkayadarina-png.github.io/finplan

## Как устроено
- Цифры хранятся в Google Таблице владельца (доступ только у владельца).
- Скрипт Google Apps Script «Финансовый планер API» (код в `apps-script/Code.gs`) опубликован как веб-приложение
  и отдаёт значения листов **только при правильном секретном ключе**.
- Сайт отправляет ключ скрипту (POST) и строит графики. Ключ вводится один раз на устройстве и хранится в браузере.
- В репозитории нет ни цифр, ни ключа.

## Файлы
- `index.html` — сайт
- `config.js` — адрес скрипта (`apiUrl`) и ID таблицы
- `apps-script/Code.gs` — код скрипта-API (копия того, что развёрнуто в Apps Script)

## Новый ключ
В редакторе Apps Script выбрать функцию `setupKey` → «Выполнить» → скопировать `API_KEY` из журнала → на сайте «Забыть ключ» и вставить новый.
Старый ключ сразу перестаёт работать.

## Структура таблицы, которую читает сайт
- Бюджет: доходы A6:C15; расходы A20:D49
- Портфель: A5:E29
- Подушка: B4–B7
- Цели: A5:E24
- Прогноз: B4–B10
- История: A5:E64

Если менять расположение ячеек в таблице, нужно обновить `index.html` (функция `fromWorkbook`) и при необходимости `RANGES` в скрипте.

Не является индивидуальной инвестиционной рекомендацией.
